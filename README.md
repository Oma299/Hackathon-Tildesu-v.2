# 🇰🇿 Tildesu (Тілдесу) — ИИ-тренажер для детей с заиканием

**Tildesu** — это проект интерактивной веб-платформы, разрабатываемой для помощи детям с заиканием и логопедическими трудностями. Цель проекта — предоставить безопасную цифровую среду, где ребенок сможет практиковаться в разговорной речи, общаясь с виртуальным ИИ-собеседником в режиме реального времени (Voice-to-Voice).

---

## 🚀 Текущий статус проекта (MVP)
На данном этапе **полностью разработана фронтенд-часть и интерактивный прототип интерфейса (UI/UX)**. 

⚠️ **Важно:** Полноценный голосовой ИИ-собеседник (модули распознавания речи STT, языковая модель LLM и синтез голоса TTS) находится на стадии проектирования. Интеграция и запуск рабочего ИИ-модуля — это главная техническая задача, под реализацию которой запрашивается финансирование.

### 🛠️ Технологический стек прототипа
- **Фреймворк:** Next.js / React
- **Стилизация:** Tailwind CSS / Shadcn UI
- **Хостинг / Деплой:** Vercel

---

## 🎯 Что реализовано в текущем интерфейсе
1. **Интерактивные ИИ-аватары:** Прототипы персонажей, с которыми дети будут вступать в диалог.
2. **Интерфейс тренажера:** Визуальная база для будущей механики Voice-to-Voice (кнопки микрофона, интерактивный чат, отображение ответов).
3. **Разделы с упражнениями:** Структурированные игровые задания на автоматизацию звуков.
4. **Десктопная веб-версия:** Интерфейс полностью спроектирован под экраны ноутбуков и персональных компьютеров (ПК) для максимально удобного и фокусного взаимодействия ребенка с платформой во время занятий.

---

## ⚠️ Текущие ограничения проекта
- Для работы голосового ИИ пользователю потребуется стабильное интернет-соединение.
- Платформа разрабатывается как вспомогательный домашний тренажер и не заменяет живого логопеда-дефектолога.
- Рекомендованный возраст для самостоятельных занятий — от 5 лет.
- На этапе MVP интерфейс оптимизирован только для ПК и ноутбуков (десктопная версия); адаптация под мобильные устройства планируется в следующих версиях.
